Several tools put an AI agent in your chat app. They differ most in one thing: whose agent does the work. Angelia, Remote Control and Claude Code's Telegram channel plugin use a CLI you already run. OpenClaw and Hermes Agent bring an agent of their own, and OpenClaw can also run Claude Code or Gemini CLI as its engine. This page is on Angelia's site, so it says where the others are the better choice, and what Angelia cannot do.

Facts checked against each project's own docs in October 2026. These projects change fast; check their docs before you decide.

Angelia

A small daemon on your Mac. It connects to WhatsApp and Telegram and starts your CLI for each chat, in that chat's own folder (a profile). It is not an agent and runs no model: the CLI you already set up does the work, with its own tools, skills, MCP servers and permission prompts. A command the profile may not run on its own comes to the chat and waits for an owner's yes; for Codex and pi, every command also runs in an OS sandbox. There is no Angelia server.

  • Pick it when: you already trust one CLI and want it in your chats, with a separate session, folder and set of rules for each chat, running in the background.
  • Limits: macOS only for now. WhatsApp needs a second number. Two chat apps, not twenty. A young project (v0.3), maintained by one person.

More: Claude Code · WhatsApp · Telegram · docs.

OpenClaw

OpenClaw is a full personal agent with its own Gateway, on any model provider, with apps for iOS and Android and the widest list of chat apps here. It can also run its turns through a local Claude Code or Gemini CLI, as the main engine or a fallback, with sessions and warm processes. It has no bundled Codex CLI backend; Codex goes through an app-server harness. With the Gateway's tools on, OpenClaw's own exec replaces Claude's Bash, and the permission policy is OpenClaw's, not Claude Code's.

  • Pick it when: you want many chat apps, Linux or Windows, phone apps, or an agent that is not tied to one CLI.
  • Keep in mind: tools run on the host unless you set up its sandbox. Even with Claude Code as its engine, the rules in front of it are OpenClaw's.

Hermes Agent

Hermes Agent, from Nous Research, is an agent of its own: memory, skills it writes itself, scheduled tasks, subagents, and five terminal backends (local, Docker, SSH, Singularity, Modal). It runs on your model provider, or on Nous Portal, an optional paid service. It calls the model's API itself; it does not run your Claude Code as the agent.

  • Pick it when: you want one agent that grows its own memory and skills, on the model you choose, on macOS, Windows or Linux.
  • Keep in mind: it is a different agent from your CLI. What you set up in Claude Code or Codex is not what answers in the chat.

Claude Code Remote Control

Built into Claude Code. A session you start on your computer with claude --remote-control, or /rc in a running one, shows up in the Claude app and at claude.ai/code. The work runs on your machine; the phone is a window into that session.

  • Pick it when: you want to keep steering one coding session from the couch, with the full session view.
  • Keep in mind: it is not a chat app, and the session is yours alone. Anthropic's Remote Control docs list the plans and what is stored.

Claude Code's Telegram channel plugin

An official MCP plugin, in research preview, that pushes Telegram messages into a Claude Code session you already have open; Discord and iMessage have their own. You start Claude Code with claude --channels plugin:telegram@claude-plugins-official. It needs Bun. Senders pair with a code and go on an allowlist, and it can relay permission prompts to the chat. On Team and Enterprise plans, it must be turned on first.

  • Pick it when: you want to ask the session you have open a quick question from Telegram, Discord or iMessage, without a separate program running.
  • Keep in mind: messages arrive only while that session is open, and every chat feeds that one session. There is no WhatsApp channel. See Anthropic's channels docs.

Which one

  • One coding session, from your phone: Remote Control.
  • A quick question into the session you have open, on Telegram, Discord or iMessage: the channel plugin.
  • Many chat apps, Linux or Windows, or an agent not tied to one CLI: OpenClaw.
  • An agent that keeps its own memory and writes its own skills: Hermes Agent.
  • The CLI you already set up, one session and folder per chat, on WhatsApp or Telegram, from your Mac: Angelia.
