Angelia connects a Telegram bot of your own to the coding agent CLI on your Mac: Claude Code, Codex, Grok Build or pi. Each chat you route gets its own session, in its own folder. Telegram is the quickest way to start: a bot is free, and @BotFather makes one in a few messages.

What you need

  • A Mac with Node 22.23.4+, 24.22.1+ or 26.12.1+ and git.
  • A supported CLI, installed and signed in: Claude Code 2.1.270+, Codex 0.157+, Grok Build 1.0.13+ or pi 0.80.4+ (backends).
  • Tested on Telegram so far: Claude Code. Codex, Grok Build and pi on Telegram are not tested yet.
  • A bot token. Open @BotFather in Telegram, send /newbot, pick a name, and keep the token it gives you.
  • Optional: brew install openai-whisper ffmpeg for voice notes.

Set it up

curl -fsSL https://useangelia.com/install | sh
angelia service install
  1. The installer checks the release's signature and starts the setup wizard. Pick Quick (one chat, one folder) or Advanced, then Telegram.
  2. Paste the bot token. It is stored on your disk, in ~/.angelia/env (mode 600), never in a chat.
  3. Pick a CLI and a folder for the first profile.
  4. Send your bot any message from your phone. The wizard shows who wrote and asks you to pair that chat.

angelia service install keeps Angelia running: it starts at login and comes back after a crash. Now send the bot "what is in this folder?". The agent answers from the profile's folder, on your Mac.

Groups and topics

  • Make the bot a group admin. Telegram's privacy mode otherwise hides plain @mentions from bots.
  • In a group, the agent answers only when someone mentions the bot or replies to it. A command tapped in the group's menu, such as /status@yourbot, counts as a mention. A route with mention: any answers every message.
  • Only the route's owners are heard, unless allow_from names others by their numeric user id, or says "*". Only owners approve commands, change the session or restart.
  • A direct chat's id is your numeric user id. A group's id is negative and starts with -100. Both appear in the daemon log the first time an unrouted chat writes.
  • A route can name one forum topic with thread:. That topic then has its own profile and session, apart from the rest of the group.
  • Messages sent as a channel or by an anonymous group admin are ignored: Angelia cannot tell who sent them.

What works

  • Approvals. A command the profile may not run on its own comes to the chat as 🔐 Bash: npm test, with a short id. An owner answers yes <id> or no <id>. No answer in ten minutes means no. This works for Claude Code, Grok Build and pi. Codex runs in its own sandbox and asks only for more access than the sandbox gives.
  • Voice notes. A voice note reaches the agent as a file, and the agent runs angelia transcribe, which uses Whisper on your Mac. An audio file the agent sends back arrives as a voice message when it can be converted to ogg/opus (ffmpeg).
  • Photos, videos and documents. Files up to 20 MB, the Bot API's limit, land in the profile's .inbox/ folder for the agent to read. The agent sends files back with angelia send-media, up to 50 MB.
  • Long answers. Progress lines while the agent works, then the answer, split at paragraph breaks into messages of up to 4,000 characters. A code block cut in two is closed and opened again. The chat shows "typing" while a turn runs.
  • A command menu. /new, /stop, /status, /resume, /model and the others are answered by Angelia itself, and are listed in Telegram's command menu. The menu is set in routed chats only, so a stranger who opens the bot does not see it.
  • Strangers get nothing. A chat that is not in the routing table gets no reply. The daemon log gets one line with its chat id.

Privacy

Angelia has no server. It reads the bot's updates from Telegram directly, from your Mac. Telegram keeps bot messages on its servers: bot chats are not end-to-end encrypted. Each turn goes to your CLI's model provider, under that CLI's own terms. The security model has the rest.

Limits

  • Angelia reads the bot's updates by long polling, and Telegram allows one reader per token. Give Angelia a bot of its own, not one another program also uses.
  • Answers are sent as plain text. Markdown marks in an answer show as typed.
  • macOS only for now, and the Mac must be on. Linux is next.
  • It is a young project (v0.3), maintained by one person.

To remove the bot itself after you uninstall Angelia, send /deletebot to @BotFather.
